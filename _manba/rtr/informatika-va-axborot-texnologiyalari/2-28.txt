## JavaScript nima va u qanday ulanadi
**JavaScript** — veb-sahifalarni interaktiv qiladigan dasturlash tili: tugma bosilganda hisob-kitob qilish, shakldagi ma'lumotni tekshirish, sahifa mazmunini yangilash, o'yin va animatsiyalar. Veb-sahifada uch til birga ishlaydi: **HTML** tuzilmani (sarlavha, matn, tugma), **CSS** ko'rinishni (rang, shrift, joylashuv), **JavaScript** esa xatti-harakatni belgilaydi. JavaScript dasturi (**skript**) brauzerning o'zida bajariladi, shuning uchun uni o'rganish uchun faqat brauzer va matn muharriri kerak. Skript HTML sahifaga `<script>` tegi ichida yoziladi yoki alohida fayl sifatida ulanadi: `<script src="dastur.js"></script>`. Brauzerdagi **dasturchi konsoli** (F12 tugmasi → «Console») xato xabarlarini ko'rsatadi va unda kodni bevosita sinab ko'rish mumkin.
```
<!DOCTYPE html>
<html>
<body>
  <h1>Birinchi skript</h1>
  <p id="natija"></p>
  <script>
    // bu izoh — dastur uni bajarmaydi
    console.log("Salom, konsol!");
    document.getElementById("natija").textContent = "Salom, sahifa!";
  </script>
</body>
</html>
```

## O'zgaruvchilar, ma'lumot turlari va operatorlar
**O'zgaruvchi** — ma'lumot saqlanadigan nomlangan joy. `let` bilan qiymati o'zgarishi mumkin bo'lgan, `const` bilan o'zgarmas o'zgaruvchi e'lon qilinadi (eski kodlarda `var` ham uchraydi). Nomlar lotin harflari bilan, ma'noli yoziladi va katta-kichik harf farqlanadi (`narx` va `Narx` — ikki xil o'zgaruvchi). Asosiy **ma'lumot turlari**: son (`let soni = 12;`, `let narx = 2.5;` — o'nli kasr nuqta bilan), satr (`let ism = "Dilnoza";`), mantiqiy (`let tolandi = true;`); qiymat berilmagan o'zgaruvchi `undefined` bo'ladi. Turini `typeof` aniqlaydi.
**Operatorlar**: arifmetik `+ - * / %` (`%` — bo'lishdagi qoldiq); solishtirish `> < >= <= === !==` (natija true yoki false); `+` satrlar bilan ishlatilsa ularni **birlashtiradi**: `"Avto" + "servis"` → `"Avtoservis"`. Muhim tuzoq: kiritish maydonidan olingan qiymat doim satr bo'ladi, shuning uchun `"5" + 5` natijasi `"55"`; hisoblashdan oldin `Number("5")` bilan songa o'tkazish kerak. `===` qiymat bilan birga turni ham solishtiradi, shuning uchun u `==` dan ishonchliroq.

## Ma'lumot kiritish va natijani chiqarish
Foydalanuvchidan ma'lumot olish uchun HTML'da kiritish maydoni yaratiladi: `<input id="masofa" type="number">`. JavaScript uni `document.getElementById("masofa").value` orqali o'qiydi. Natija `console.log()` bilan konsolga yoki elementning `textContent` xossasiga yozilib, sahifaga chiqariladi; `alert()` qisqa xabar oynasini ko'rsatadi. Kasr sonlarni chiroyli chiqarish uchun `toFixed(2)` ishlatiladi. Xato bo'lsa, konsol uni qator raqami bilan ko'rsatadi: masalan, yopilmagan qavs yoki qo'shtirnoq — **sintaksis xatosi**, noto'g'ri yozilgan o'zgaruvchi nomi — «is not defined» xatosi.
