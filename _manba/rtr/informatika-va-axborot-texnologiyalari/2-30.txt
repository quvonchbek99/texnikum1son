## Funksiyalar
**Funksiya** — nom berilgan va kerak bo'lganda chaqiriladigan kod bloki. U bir xil amalni dasturning turli joylarida qayta yozmaslik, katta dasturni kichik va tushunarli qismlarga bo'lish imkonini beradi. Funksiya `function` so'zi bilan e'lon qilinadi; qavs ichidagi **parametrlar** — tashqaridan beriladigan qiymatlar uchun «bo'sh joylar», chaqirishda beriladigan haqiqiy qiymatlar esa **argumentlar** deyiladi; `return` natijani qaytaradi va funksiyani tugatadi:
```
function narx(xizmat, soat) {
  let stavka = 0;
  if (xizmat === "diagnostika") stavka = 80000;
  else if (xizmat === "tamir") stavka = 120000;
  return stavka * soat;
}
console.log(narx("tamir", 2));   // 240000
```
Funksiya ichida `let` bilan e'lon qilingan o'zgaruvchilar **mahalliy** — ular faqat funksiya ichida mavjud. Qisqa funksiyalar strelka ko'rinishida ham yoziladi: `const kvadrat = x => x * x;`.

## HTML shakllari va hodisalar
**HTML shakli** foydalanuvchidan ma'lumot olish uchun xizmat qiladi. Asosiy elementlar: `<input type="text">` (matn), `type="number"`, `type="email"`, `type="date"` (sana tanlash), `type="checkbox"` (belgilash), `type="radio"` (bittasini tanlash), `<select>` (ochiluvchi ro'yxat), `<textarea>` (ko'p qatorli matn), `<button>`; har bir maydonga `<label>` bilan tushunarli yorliq beriladi. `required`, `min`, `max`, `pattern` atributlari brauzerning o'zida oddiy tekshiruvni yoqadi.
**Hodisa** — foydalanuvchi yoki brauzer harakati: tugmani bosish (`click`), maydonga yozish (`input`), tanlovni o'zgartirish (`change`), shaklni yuborish (`submit`), sichqonchani olib kelish (`mouseover`), tugma bosish (`keydown`). Hodisaga javob beradigan funksiya **hodisa ishlovchisi** deyiladi. U `onclick="..."` atributi bilan yoki zamonaviyroq usulda `addEventListener` bilan ulanadi:
```
const shakl = document.getElementById("yozilish");
shakl.addEventListener("submit", function (e) {
  e.preventDefault();               // sahifa qayta yuklanmasin
  const ism = document.getElementById("ism").value.trim();
  if (ism.length < 2) {
    alert("Ismni to'liq kiriting");
    return;
  }
  document.getElementById("natija").textContent = ism + ", siz ro'yxatga olindingiz!";
});
```
Shakl yuborilganda brauzer odatda sahifani qayta yuklaydi; `preventDefault()` buni to'xtatib, ma'lumotni JavaScript'da tekshirish va natijani shu sahifada ko'rsatish imkonini beradi. Belgilash katakchasining holati `.checked` (true yoki false) bilan o'qiladi.

## Qalqib chiquvchi oynalar. Yakuniy nazorat
Brauzerda uchta oddiy **qalqib chiquvchi oyna** bor: `alert("...")` — xabar ko'rsatadi va faqat «OK» tugmasi bor; `confirm("...")` — tasdiq so'raydi va «OK» bosilsa `true`, «Bekor qilish» bosilsa `false` qaytaradi (masalan, ma'lumotni o'chirishdan oldin); `prompt("...")` — qisqa matn kiritishni so'raydi va kiritilgan satrni yoki bekor qilinganda `null` qaytaradi. Bu oynalar sahifa ishini to'xtatib qo'yadi va foydalanuvchini bezovta qiladi, shuning uchun ulardan kam va faqat muhim holatlarda foydalaniladi; xatolarni sahifaning o'zida, maydon yonida ko'rsatish qulayroq. Brauzerlar foydalanuvchi so'ramagan yangi oynalarni (reklama pop-up'larini) avtomatik bloklaydi.

function kvadrat(x) {
