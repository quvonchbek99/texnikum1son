## Massivlar
**Massiv** — bir nechta qiymatni bitta nom ostida tartib bilan saqlaydigan tuzilma. U kvadrat qavslarda yoziladi: `let narxlar = [12000, 8500, 15000];`, `let ustalar = ["Anvar", "Bekzod", "Sanjar"];`. Har bir **element**ning tartib raqami — **indeks**i bor va u **0 dan** boshlanadi: `narxlar[0]` → 12000, `narxlar[2]` → 15000. Elementlar soni `narxlar.length` bilan topiladi (3), oxirgi element indeksi esa `length − 1`. Elementni o'zgartirish: `narxlar[1] = 9000;`; oxiriga qo'shish: `narxlar.push(20000);`; oxirgisini olib tashlash: `narxlar.pop();`; element bor-yo'qligini tekshirish: `ustalar.includes("Bekzod")` → true. Mavjud bo'lmagan indeksga murojaat `undefined` qaytaradi.

## Shartli buyruqlar
**Shartli buyruq** dastur qaysi yo'ldan borishini shartga qarab hal qiladi:
```
let ball = 78;
if (ball >= 86) {
  console.log("A'lo (5)");
} else if (ball >= 71) {
  console.log("Yaxshi (4)");
} else if (ball >= 56) {
  console.log("Qoniqarli (3)");
} else {
  console.log("Qoniqarsiz (2)");
}
```
Shartlar yuqoridan pastga tekshiriladi va birinchi to'g'ri kelgan blok bajariladi (78 uchun «Yaxshi (4)»). **Mantiqiy operatorlar** shartlarni birlashtiradi: `&&` (va) — ikkala shart ham rost bo'lsa; `||` (yoki) — kamida bittasi rost bo'lsa; `!` (emas) — shartni teskarisiga aylantiradi. Masalan: `if (qoldiq < 10 && buyurtmaBor === false)` — qoldiq kam va buyurtma berilmagan bo'lsa.

## Sikllar
**Sikl** bir xil amallarni ko'p marta takrorlaydi. **for** sikli takrorlash soni ma'lum bo'lganda qulay: `for (let i = 0; i < narxlar.length; i++) { ... }` — `i` hisoblagich 0 dan boshlanadi, shart rost ekan sikl davom etadi, har aylanishda `i` bittaga oshadi. **while** sikli shart rost bo'lgunicha ishlaydi: `while (qoldiq > 0) { qoldiq = qoldiq - 3; }`. **for...of** massiv elementlarini bevosita aylanib chiqadi: `for (let narx of narxlar) { jami = jami + narx; }`. Agar shart hech qachon yolg'on bo'lmasa, **cheksiz sikl** hosil bo'ladi va sahifa «qotib» qoladi — hisoblagich o'zgarishini doim tekshiring; sikldan muddatidan oldin chiqish uchun `break` ishlatiladi. Massiv, shart va sikl birgalikda eng ko'p uchraydigan vazifalarni hal qiladi: yig'indi va o'rtacha qiymatni topish, eng katta yoki eng kichik elementni aniqlash, shartga mos elementlarni sanash yoki ajratib olish.
```
let baholar = [92, 78, 61, 49, 85];
let jami = 0, eng = baholar[0], otdi = 0;
for (let b of baholar) {
  jami += b;
  if (b > eng) eng = b;
  if (b >= 56) otdi++;
}
console.log("O'rtacha:", jami / baholar.length);  // 73
console.log("Eng yuqori:", eng, "O'tganlar:", otdi); // 92, 4
```
