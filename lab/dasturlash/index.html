⌨️ Dasturlash laboratoriyasi

Dasturchi vositalari va asosiy tushunchalar: kod muharriri, algoritm, o‘zgaruvchi, shart, sikl, funksiya; brauzerda ishlaydigan JavaScript mashqlari.

Elementar dasturlash· Kompyuter tarmoqlari va IT-servis

Jihozlar pasporti

01🧑‍💻 Kod muharriri (VS Code)

Dastur kodini yozish, xatolarni ko‘rsatish va ishga tushirish uchun.

Tuzilishi

  1. Fayllar paneli
  2. Muharrir oynasi (sintaksis yoritilishi)
  3. Terminal
  4. Kengaytmalar

Ishlatish tartibi

  1. Loyiha papkasini oching.
  2. Fayl kengaytmasini to‘g‘ri bering (.js, .py, .html).
  3. Kodni formatlang va izohlar yozing.
02🧭 Algoritm va blok-sxema

Masalani yechish uchun aniq, chekli qadamlar ketma-ketligi.

Tuzilishi

  1. Boshlanish/tugash (oval)
  2. Amal (to‘rtburchak)
  3. Shart (romb)
  4. Kiritish/chiqarish (parallelogramm)
  5. Strelkalar

Ishlatish tartibi

  1. Masalani kichik qadamlarga bo‘ling.
  2. Blok-sxemasini chizing.
  3. Keyin kodga o‘giring.
03📦 O‘zgaruvchi va ma’lumot turlari

Qiymatni nom bilan saqlaydigan «quti»: son, matn (satr), mantiqiy (true/false), massiv.

Tuzilishi

  1. Nom
  2. Qiymat
  3. Tur (number, string, boolean)

Ishlatish tartibi

  1. Tushunarli nom bering (narx, ism).
  2. JavaScriptda let yoki const bilan e’lon qiling.
04🔀 Shart operatori (if/else)

Shartga qarab dasturning turli tarmoqlarini bajaradi.

Tuzilishi

  1. if (shart)
  2. else if
  3. else
  4. Taqqoslash: >, <, ===, !==

Ishlatish tartibi

  1. Shartni to‘g‘ri yozing.
  2. Barcha holatlarni ko‘rib chiqing.
05🔁 Sikl (for, while)

Amallarni ko‘p marta takrorlash.

Tuzilishi

  1. Boshlang‘ich qiymat
  2. Davom etish sharti
  3. Qadam (i++)
  4. Sikl tanasi

Ishlatish tartibi

  1. Sikl albatta tugashiga ishonch hosil qiling — cheksiz sikl dasturni muzlatadi.
06🧩 Funksiya

Qayta ishlatiladigan nomlangan kod bo‘lagi: parametr oladi, natija qaytaradi.

Tuzilishi

  1. Nomi
  2. Parametrlar
  3. Tanasi
  4. return (natija)

Ishlatish tartibi

  1. Bitta funksiya bitta ishni bajarsin.
  2. Parametr va natija nomlarini tushunarli qiling.
